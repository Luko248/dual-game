# DUAL — mobile shell

Expo app that ships the web game to the App Store. The game itself is a
single self-contained HTML asset (`assets/game/index.html`, gitignored)
generated from the repo root:

```bash
bun run build:mobile
```

Then, in this directory:

```bash
bun install
bunx expo install --fix   # align native module versions with the Expo SDK
bunx expo run:ios         # dev build (Expo Go is not enough)
```

Full release pipeline: see [`../docs/IOS_RELEASE.md`](../docs/IOS_RELEASE.md).

`ios/` and `android/` are generated by `expo prebuild --clean` and never
committed.
